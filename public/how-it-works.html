How Quibble runs a 250-player quiz with no server

Quibble is a real-time multiplayer quiz built only from serverless AWS pieces. One person hosts, everyone joins from their phone, and the whole room races the same countdown. Press the buttons below to watch a request travel through it, break things on purpose, then play a round yourself.

      Your turn

      Run it yourself

      Start on your laptop: the local dev server runs the real Lambda code against DynamoDB Local, so you need no AWS account. When you're ready, the same repo deploys to your own account with three commands, and the step-by-step deploy guide explains each one, from account safety to teardown.

      1. Play locally

      Needs Node.js 22 and Docker Desktop. Opens on localhost:5050.

      git clone https://github.com/Yash19k/quibble.git
cd quibble
npm install
docker run -d -p 8000:8000 --name quibble-dynamodb amazon/dynamodb-local
npm run dev

      2. Deploy to AWS

      Needs the AWS CLI logged in and the SAM CLI. Prints your HTTPS link at the end. First time on AWS? The deploy guide walks through every step.

      npm run preflight
npm run deploy
npm run seed

      3. Clean up

      Empty the website bucket, then delete the whole stack. Nothing is left to bill you.

      aws s3 rm s3://<FrontendBucketName> --recursive
sam delete --stack-name quibble
