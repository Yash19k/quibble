How to play

  1. 01

    Host a room

    Pick categories, the number of questions and how long players get to answer each one.

  2. 02

    Share the code

    Friends join with a six-letter room code. Everyone sees the same question at the same moment.

  3. 03

    Race to answer

    A correct answer is worth up to 1,000 points, dropping to 500 as the clock runs out. Most points wins.

How it works

There's no game server. Rooms, answers and scores move through managed AWS services. Pick a moment in a game to see which ones do the work.

    The website is just files

    The pages, styles and scripts sit in an S3 bucket, and S3 hands them to your browser. Nothing runs until somebody plays.
